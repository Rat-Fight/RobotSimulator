# RobotSimulator

This repository contains the **Robot Simulator** for the Rat-Fight team. The simulator lets drivers practice driving the robot in a software environment without physical hardware. It helps with testing, training, and refining driver skills.

## About

RobotSimulator is designed so that drivers can practice robot driving, autonomous routines, and control logic in a simulated setting before running on an actual robot.

## Getting Started

To use the simulator locally, follow these steps:

1. **Clone the repository**

git clone https://github.com/Rat-Fight/RobotSimulator.git


2. **Open the simulator**
- Navigate into the project folder  
- Open `simulator/index.html` in a web browser  

3. **Use the simulator**
- Drive the simulated robot using provided controls  
- Practice autonomous paths and logic

## Usage

The simulator is intended for:

- Driver practice
- Testing autonomous routines
- Trying out robot control ideas without hardware

Simply load the HTML file in a modern browser to begin.

## Development

If you want to extend the simulator:

1. Modify or add JavaScript logic in the `js/` folder
2. Update UI styles in the `css/` folder
3. Add new assets under `assets/`
4. Test changes by refreshing `index.html` in a browser
